# plugin-three-js-animate

## Overview

A plugin for displaying threeJS animations as stimuli

## Loading

### In browser

```html
<script src="https://unpkg.com/@jspsych-contrib/plugin-three-js-animate">
```

### Via NPM

```
npm install @jspsych-contrib/plugin-three-js-animate
```

```js
import jsPsychPluginThreeJsAnimate from "plugin-three-js-animate";
```

## Compatibility

`@jspsych-contrib/plugin-three-js-animate` requires jsPsych v8.0.0 or later.
