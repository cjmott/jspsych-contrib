# plugin-canvas-multi-choice

## Overview

A plugin to create a question type with a canvas stimulus and a multichoice response option.

## Loading

### In browser

```html
<script src="https://unpkg.com/@jspsych-contrib/plugin-canvas-multi-choice">
```

### Via NPM

```
npm install @jspsych-contrib/plugin-canvas-multi-choice
```

```js
import jsPsychPluginCanvasMultiChoice from "plugin-canvas-multi-choice";
```

## Compatibility

`@jspsych-contrib/plugin-canvas-multi-choice` requires jsPsych v8.0.0 or later.
